# Projects

A project is a folder for work. It groups the chats, rooms and bot teams that belong to one job, and
keeps a running total of what they have cost.

Nothing forces you to use them. A project is a label you put on work you already do — the site runs
perfectly well with everything unfiled, which is exactly how it ran before projects existed.

## When they earn their keep

**When somebody asks "what did that cost us?"** Credits are spent a message at a time, all over the
place. A project is the only thing that adds them up around one piece of work.

**When work has a beginning and an end.** A project has a status — Active, Paused, Done, Archived —
so finished work stops competing for attention with live work.

**When more than one person needs to find the same things.** "It's in the Website refresh project"
is a better answer than "search your chats for October".

## Creating one

Admin → Teamwork → Projects. Name it, and optionally give it a colour, a description and a budget.

Then file things into it: a bot team has a **Project** setting, and runs started by that team join
its project automatically.

## About the budget

Be clear about what the budget does, because the word promises more than it delivers here.

**It is a warning line, not a wall.** The project page shows what has been spent against it and
turns amber past 70% and red past 90%. It is checked before a bot team run starts.

**It cannot stop a message mid-conversation.** Credits come out of one wallet shared by everyone on
the team, and that wallet is what actually runs out. A project budget tells you a piece of work is
getting expensive; it does not make the platform refuse the next message.

If you need a hard limit, the place to set it is the wallet itself, or the per-team caps in
**Bot teams** — those *are* enforced, on every step.

Leaving the budget blank means no line at all, which is different from setting it to zero.

## Deleting a project

**Deleting a project never deletes what is inside it.** The chats, rooms and teams filed under it
survive and simply become unfiled.

This is deliberate and it is tested. Tidying a folder should never be a way to lose a month of
conversations, so the platform is built so that it cannot be.

If you want work out of sight without deleting anything, set the status to **Archived** instead.
