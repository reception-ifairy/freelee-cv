# Front page

**Content → Frontpage.** Rearrange your home page without touching code.

Your home page is a stack of blocks. Each one can be moved, hidden or edited.

| Block | Shows | Editable text? |
|---|---|---|
| **Hero** | The big headline, subtitle and two buttons | Yes |
| **Categories** | Category pills with persona counts | No — comes from your categories |
| **Featured personas** | Personas ticked *Featured on home* | No — comes from your personas |
| **How it works** | Three steps with icons | Yes |
| **Pricing** | Your credit packs | No — comes from your packs |
| **Blog** | Latest posts | No — comes from your posts |
| **Call to action** | The closing signup block | Yes |
| **Custom content** | Anything you write | Yes |

## The controls

- **Arrows** move a block up or down
- **Eye** hides a block without deleting it — the fastest fix when a section looks wrong
- **Add custom section** appends a new free-text block

Changes appear on the live site immediately.

## Why some blocks have no editable text

Blocks like Categories and Featured personas pull live from your data. Their headings are handled
by [Translations](/admin/handbook/translations) instead. This is deliberate: if the same heading
could be edited in two places, the two would eventually disagree and you'd have no way to tell
which one was winning.

## Custom content blocks

The only block you can add more than once. Each has a heading, body text (Markdown, so `**bold**`
and lists work), an optional image, and an optional button.

Good for a testimonial, a seasonal announcement, or an explanation the fixed blocks don't cover.

## Hiding vs deleting

Core blocks can only be **hidden**, never deleted — there'd be no way to get them back. Custom
blocks can be deleted, because you can always make another.
